How to update this guide

The guide is built from files in docs/guide-source/, so it can be kept up to date as the project changes:

guide.htmlThe cover, the page styles (A4, brand colours) and the contents placeholder.
chapters/*.htmlOne file per chapter, joined in name order. Edit the words here.
assets/*.svgThe four diagrams (edit them in any text editor or vector drawing program).
filemap.jsonOne plain-English description per project file, used for chapter 5.
build.mjsThe builder.
  1. Edit the chapter or filemap.json. Code snippets are written as <pre data-file="src/app.js" data-find="text on the first line" data-lines="5"></pre>: the builder copies the real lines from the project, so they never go stale.
  2. From the project folder run node docs/guide-source/build.mjs. It needs Node 20+ and Microsoft Edge or Google Chrome, which it finds by itself (or set GUIDE_BROWSER to the browser's path). Nothing to install.
  3. It prints a list of anything to fix: a snippet whose text was not found (the build stops), a project file with no description, or a description for a file that no longer exists.
  4. It writes docs/Senior-Paddi-Beginners-Guide.pdf. It prints twice: the first print finds the page of every heading, the second fills those page numbers into the contents.
  5. To preview without making a PDF, run it with --html-only and open docs/guide-source/out/guide.html in a browser.

When you add a file to the project, add one line for it to filemap.json. When you change how a feature works, update its chapter and rebuild.
