Chapter 11Troubleshooting

When something goes wrong, read the message in the terminal first: SeniorPadi's start-up code tries hard to say what is wrong in plain words. Then find it in the tables below.

Where errors appear
  • The terminal running the site: start-up problems and crashes (with the file and line number).
  • The browser page: SeniorPadi shows a friendly error page (views/error.ejs) instead of technical details. The technical details are printed in the terminal at the same moment.
  • The browser's developer tools (F12 → Console): problems with the small scripts in public/js/.

Pages and templates

You seeLikely causeFix
"We couldn't find that page." (in plain Express this would be Cannot GET /page)No route answers that address and method.Check the spelling of the address; check a router.get('/page', ...) exists and its file is plugged in with app.use in src/app.js; a form with method="post" needs a router.post.
Failed to lookup view "x" in views directoryThe name in res.render('x') does not match a file in views/.Use the path inside views/ without .ejs, e.g. 'auth/login'. Names are case-sensitive on Render (Linux).
Cannot find module 'ejs' (or "ejs is not defined")Packages not installed, or EJS not set as the view engine.Run npm install. The engine is set by app.set('view engine', 'ejs') in src/app.js; don't remove it.
ReferenceError: something is not defined, pointing at an .ejs lineThe template uses a variable the route did not pass.Pass it in res.render, or guard it with typeof something !== 'undefined'.
Could not find the include fileWrong path in include(...).Paths are relative to the current template (../partials/... from a sub-folder).
SyntaxError in an .ejs fileAn if or loop is not closed, or a %> is missing.Match every { with a <% } %>.
Raw HTML code shows as text on the page<%= include(...) %> used instead of <%-.Use the dash for includes.
"This page was open too long. Go back, refresh the page and try again."The form's security token is missing or old (CSRF check).Refresh and send again. For a form you wrote, add the hidden _csrf field.
"Too many tries. Please wait a few minutes and try again."A rate limit (src/middleware/rateLimit.js), e.g. 10 log-ins in 15 minutes.Wait. On your own computer, restarting the site also clears the counts (they are kept in memory).
Every page sends you to "Change password"Staff reset this account's password, so mustChangePassword is on.Choose a new password; that is intended (requirePasswordChanged in src/middleware/auth.js).

Starting the site

You seeLikely causeFix
EADDRINUSE: address already in use :::3000Another copy of the site (or another program) already uses port 3000.Stop the other terminal with Ctrl+C. If you can't find it: Windows netstat -ano | findstr :3000 then taskkill /PID <number> /F; macOS/Linux lsof -i :3000 then kill <PID>. Or use another port (PORT=3001 in .env).
The database address is missing.No .env file, wrong folder, or the address for your DB_TARGET is empty.Create .env next to package.json (chapter 4, step 5).
SyntaxError: Unexpected token ... in JSON mentioning locales/A missing comma or quote in en.json/yo.json.Open the file; VS Code underlines the mistake in red.
! There is no admin account yet.ADMIN_PHONE/ADMIN_PASSWORD missing, or the password is under 8 characters.Fix .env and restart, or run npm run create-admin -- "Full Name" 08031234567 YOUR_PASSWORD_HERE.
! The stylesheet is missing and could not be built.public/css/main.css was deleted and Tailwind could not run.Run npm install, then npm run build:css.
Database update ... failed: ...A migration file has an error, or the database is in an unexpected state.Read the message after "failed:"; fix the new migration file (never an old one) and restart.

Database connection

Run npm run db:check first: it prints which database is being used, whether the name could be found and whether it connected.

Code in the messageMeaning and fix
ECONNREFUSEDNothing is listening at that address: PostgreSQL is not running (start it), or the port in the address is wrong (usually 5432).
28P01Wrong password in the database address.
3D000 / database "..." does not existCreate the database (chapter 4, step 4), or fix its name at the end of the address.
ENOTFOUND / EAI_AGAINThe host name can't be found: no internet, a typo in a Neon address, or a network blocking it. Try another network, or use DB_TARGET=local for now.
SSL / certificate errorsOnly on unusual hosts. Neon is handled automatically; for others see DB_SSL and DB_SSL_STRICT in src/config/database.js.
Tests fail with no databasenpm test needs TEST_DATABASE_URL pointing at a separate, empty database (it is wiped).

Looks and pictures

You seeLikely causeFix
Style changes don't showThe stylesheet wasn't rebuilt, or the browser kept the old copy.Run npm run build:css; hard-refresh (Ctrl+F5). On the live site raise ?v=ui5 in header.ejs. Never edit main.css directly.
A new Tailwind class does nothingIt is in a file Tailwind does not scan, or it was built from text joined in code.Classes must appear whole in views/ or public/js/ (see @source in input.css), then rebuild.
Page has no styling at allmain.css missing or not loading.npm run build:css; check the browser's Network tab (F12) for a 404 on /css/main.css.
Icons are empty squaresFont Awesome loads from the internet (CDN).Check the internet connection.
A picture doesn't showWrong address, wrong capital letters, or the file was never committed.Use /images/... (not /public/images/...); match capitals exactly (Render is case-sensitive); new files in public/images/ need git add -f because of .gitignore.
Texts and emails don't arriveBrevo is not set up, or NOTIFY_DRY_RUN=true.Look in the terminal for [sms dry run]; that is where they go in dry-run mode. Add Brevo keys to send for real.
Event text stays English in YorùbáNo GOOGLE_TRANSLATE_API_KEY.Expected; menus and buttons are still Yorùbá (they come from locales/yo.json).

Things to know: unclear parts and possible bugs

These were found while writing this guide. None stops the site working today, but each is worth a decision.

#WhatDetails
1start-windows.bat copies a missing fileIt runs copy .env.example .env, but there is no .env.example in the project. Adding one (with placeholders only, like chapter 4's) would fix it.
2.gitignore hides new picturesThe line images/ matches public/images/ too, so new pictures are silently left out of commits. If it was meant for docs/images/ only, change it to /docs/images/.
3Upload warning is out of dateStart-up says uploads are "switched off" without Cloudinary, but src/services/cloudinary.js saves them locally instead (public/uploads/, storage/ids/). On Render those local files disappear on every restart, so Cloudinary is still needed there.
4Two GitHub addressesREADME.md and docs/MVP.md point to Otani-ibe/SeniorPadi_Capstone; the project's Git remote is Ask4mike/seniorpaddi-frontend.
5Confirm password is browser-onlyOn Create account, "Confirm password" is checked by public/js/ui.js only; the server never sees it. With JavaScript off, nothing compares the two.
6Image licences unknownThe six event photos have no recorded source or licence (IMAGE_CREDITS.md). Verify or replace before launch.
7Old notes and filespublic/images/README.md is partly out of date; public/images/hero.png is unused; the hero's on-yolk class name is left over from the yellow version.
8Rate limits reset on restartexpress-rate-limit keeps its counts in memory, so a restart (or several servers) resets them. Fine for one small server.
9No "Remember me"The log-in page has no "Remember me" box; instead every session lasts 30 days (src/config/session.js).
What you learned
  • Read the terminal first; then npm run db:check for database trouble.
  • Most page errors are a missing route, a wrong view name, or a variable the route didn't pass.
  • Most "my change doesn't show" problems are an unbuilt stylesheet or a cached file.
