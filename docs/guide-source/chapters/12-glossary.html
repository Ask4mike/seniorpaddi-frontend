Chapter 12Glossary

Every technical word in this guide, A to Z, in plain English.

TermMeaning
AdminA staff account (role: 'admin'). Staff use the pages under /admin.
Alt textA written description of a picture for people who can't see it (read aloud by screen readers). alt="" means "decoration, skip it".
API / API keyA way for one program to ask another for something over the internet (SeniorPadi asks Brevo to send a text). A key is the password that program uses.
async / awaitJavaScript words for "this takes time; wait for the answer before carrying on".
BranchA separate line of work in Git, so changes can be tried without touching main.
BrowserThe program that shows web pages (Chrome, Edge, a phone's browser).
bcrypt / hashA one-way scramble of a password. The site stores the hash, never the password.
Cache / cache-bustingBrowsers keep copies of files to save data. Adding ?v=ui5 to a file's address and changing it forces a fresh copy.
CDNA fast file server on the internet. Font Awesome icons come from one.
CLICommand-line interface: a program you use by typing commands in a terminal.
CloneDownload a copy of a Git repository with its whole history.
Column / row / tableA database table is like a spreadsheet: each row is one thing (a user), each column one detail (their phone).
CommitA saved snapshot of your changes in Git, with a short message.
Component classA named bundle of styles in input.css, like .btn-glow.
ControllerIn many projects, the code that answers a request. Here that code lives inside the route files.
CookieA small label the server gives the browser, which the browser sends back with every request. SeniorPadi's cookie links you to your session.
CronA timetable for jobs, written like 0 8 * * * (8:00 every day).
CSSThe language that controls how pages look.
CSRF / CSRF tokenA trick where another site secretly submits a form as you. The token is a secret in every form that proves it came from the real page.
DatabaseA program that stores information permanently. SeniorPadi uses PostgreSQL.
DeployPut a new version of the site online (Render does it after every push to GitHub).
Design tokenA named design value (a colour, a size) in the @theme block.
Dry runPretend mode: texts and emails are printed in the terminal instead of sent.
EJSEmbedded JavaScript templates: HTML with holes the server fills in.
Environment variable / .envA setting given to the program from outside its code. On your computer they live in the .env file.
EscapingTurning characters like < into harmless text so typed input can't become code. <%= %> escapes.
ExpressThe web framework: it matches addresses to functions and runs middleware.
Flash messageA one-time message shown on the next page ("Welcome, Ade!"), then forgotten.
FrameworkA ready-made skeleton for building a kind of program.
GET / POSTThe two kinds of request used here: GET asks to see a page, POST sends a form.
Git / GitHubGit records every change to the code; GitHub stores that history online.
Hard refreshReload ignoring saved copies: Ctrl+F5 (Cmd+Shift+R on a Mac).
HTMLThe language web pages are written in.
i18nShort for "internationalisation" (18 letters between i and n): showing the site in several languages.
Include / partialA small template placed inside others (views/partials/).
JavaScriptThe programming language of the server code and the browser scripts.
JSONA strict text format for data, used by package.json and locales/*.json.
Key (locale key)The name of a sentence in locales/, like login.submit.
Lazy loadingWaiting to download a picture until it is about to be seen.
localhost"This computer". localhost:3000 is the site running on your own machine.
Lock / transactionA transaction groups database steps so they all happen or none do; a lock makes others wait. Together they stop overbooking.
MiddlewareA function every request passes through before reaching its route (checks, loading the user).
MigrationA file that changes the shape of the database (adds a table or column). Each runs once.
ModelThe JavaScript description of one database table (src/models/).
NeonA company that hosts PostgreSQL databases online; the live site's database.
Node.jsThe program that runs JavaScript outside a browser.
nodemonA helper that restarts the site whenever you save a file.
npm / packagenpm downloads packages (code others shared) and runs the project's commands.
ORMA tool (here Sequelize) that lets you use database tables as JavaScript objects.
OTPOne-time password: the 6-digit code sent to confirm a phone.
PortA numbered door on a computer that a program listens on (3000 for SeniorPadi).
PostgreSQLThe database program SeniorPadi uses.
Pull request (PR)A request on GitHub to merge one branch into another, where changes are reviewed.
Rate limitA cap on how often someone can try something (e.g. logging in).
RedirectThe server telling the browser "go and ask for this other page instead".
RenderThe company that runs the live website (configured by render.yaml).
Rendering (server-side)Building the finished HTML on the server before sending it, as SeniorPadi does.
Repository (repo)A project folder tracked by Git, with all its history.
Request / responseThe browser's question to the server, and the server's answer.
res.localsData that Express adds to every template (currentUser, t...).
ResponsiveA layout that adapts to screen size, from phones to large monitors.
RouteAn address plus the function that answers it, e.g. router.get('/login', ...).
ScriptletAn EJS tag that runs code without printing: <% %>.
Seed / demo dataSample data put into the database for trying the site (npm run seed:local).
SequelizeThe ORM SeniorPadi uses to talk to PostgreSQL.
ServerThe program (and computer) that answers requests.
SessionThe server's memory of a visitor between requests (who is logged in, which language).
Socket.IO / WebSocketAn always-open line between browser and server, used for live chat.
Soft deleteMarking a row as deleted instead of removing it (paranoid: true on Users).
SQLThe language databases understand. Sequelize writes it for you.
SSLEncryption for a connection, needed by online databases like Neon.
Static filesFiles sent exactly as they are (public/): CSS, fonts, pictures, scripts.
SVGA picture format made of shapes, so it stays sharp at any size.
Tailwind CSSA styling tool built from small class names like text-lg.
TemplateA page with gaps for data (an .ejs file).
TerminalA window where you type commands (PowerShell, Terminal).
TestA small program that checks the site behaves correctly (npm test).
UTC / Lagos timeTimes are stored in UTC (world standard time) and shown in Lagos time (one hour ahead).
ViewA page template in views/.
WebPA modern picture format, usually smaller than JPG.
XSSCross-site scripting: an attack that sneaks code into a page through typed text. Escaping prevents it.
